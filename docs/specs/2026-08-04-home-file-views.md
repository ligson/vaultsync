# 首页文件视图

## 目标

首页同步目录同时满足手机快速浏览和桌面文件管理场景。视图切换只改变展示层，所有视图
共用同一份文件记录、同步状态和操作回调，不改变本地文件、服务器对象、上传队列或加密密钥。

## 视图

- **列表**：采用当前目录浏览，只显示文件/文件夹图标和名称；同步结果使用状态图标表达，点击、悬停或长按可查看完整状态，不重复显示大小、日期和“服务器已备份”等文字。文件夹点击后进入下一级，顶部面包屑可快速回到根目录或任意上级目录，适合手机快速浏览。
- **详细**：显示名称、相对路径、大小、修改时间、统一状态图标与短文字以及操作菜单；桌面宽度下可点击列头排序，适合 macOS、Windows
  和 Linux 桌面端。
- **图标**：文件和目录以网格卡片显示，状态图标固定在缩略图角落；当前设备上仍存在的普通图片使用受限解码尺寸的本地缩略图，相册资源使用系统媒体库按需生成的受限缩略图。已经按清理策略删除本地副本、相册资源或只有远端密文的文件继续显示类型图标。不会为了网格绘制批量下载和解密远端原图，避免大目录占用网络、内存和电量。

三种视图都支持按名称/修改时间/大小/同步状态排序、预览、下载到本地、删除服务器备份、查看详细信息和原有目录操作。跨同步目录的文件名/路径搜索统一由独立的搜索中心提供，详见 `docs/specs/2026-08-22-search-center.md`。文件“详细信息”弹窗按常规、同步状态、来源与保护、服务器信息和任务信息分组，展示路径、字节大小、时间、状态、加密、对象/版本/任务 ID、哈希、上传进度和错误等已有元数据；打开弹窗不读取文件内容，也不发起网络请求。排序和搜索只改变当前内存中的展示顺序，不会重建上传任务。

## 一致性规则

- 三种视图和文件夹汇总共用同一份状态映射。已同步、仅云端、待上传/续传、待清理、待确认、上传失败和无法解密分别使用稳定的图标、短文字与颜色；完整状态始终保留在提示和属性窗口中。
- 文件时间统一优先采用服务器备份更新时间，没有远端记录时采用本地修改时间；解析后转换为设备本地时区并显示为 `yyyy-MM-dd HH:mm`，不直接混入 ISO 原始字符串。
- 点击文件时，有预览能力则打开预览；没有预览能力则打开详细信息。文件菜单固定按“在线预览、下载到本地、详细信息、删除服务器备份”排列，不支持的操作不显示。
- 工具栏区分当前目录直接子项数与同步目录总文件数。排序支持升序和降序，名称默认升序，大小、时间和状态首次选择时默认降序。
- 视图、排序字段和排序方向只作为设备本地 UI 偏好保存，切换目录、刷新或重启 App 后继续沿用；无效的历史偏好安全回退到列表、名称升序。

## 下载

- 下载复用现有鉴权、密文下载和本地解密链路，服务器仍只保存密文。
- macOS、Windows 和 Linux 使用系统“另存为”窗口，Android 先选择保存目录。
- iOS 保存到 `文件 App/VaultSync Downloads`，并开启系统文件共享和原地打开能力。
- Android 和 iOS 目标位置已有同名文件时自动增加数字后缀，不覆盖原文件；桌面端是否覆盖由
  系统保存窗口确认。
- 保存过程中显示“下载、解密并保存”状态；同一个文件不能同时启动多个下载任务，失败时显示
  可读错误。取消系统保存窗口不会下载文件。

## 目录导航与性能约束

- 每次只构建当前目录的直接子目录和文件；列表/详细视图每批最多 150 项，图标视图因需要解码本地图片而收紧为每批最多 48 项。图标视图不引入远端原图批量下载。
- 搜索中心的过滤在本地已有元数据上执行，不触发扫描或远端请求；目录文件树只负责当前目录导航。
- 面包屑和“返回上级”只改变本地展示路径，不重新加载远端文件列表；视图切换不触发扫描或上传。
- 文件展示时间、状态和文件夹汇总由已有元数据计算，不读取文件内容；偏好更新只写入三个小型 `SharedPreferences` 字段。
- 同步状态页和相册清理页按页展示任务，每页最多 40 项；翻页只改变当前展示页，不删除、截断或重排本地任务队列。
- 下载由用户逐文件触发，选定目标后异步执行，不因切换视图重新开始。当前密文格式需要完整
  校验后才能写出明文，因此单文件下载仍会占用与文件大小相近的临时内存；界面不会同步阻塞。

## 数据影响与回滚

- 本次不修改 SQLite、服务端对象、上传队列、同步历史、目录绑定或加密密钥；只新增可丢弃、可回退的本地文件浏览偏好。
- 只有用户明确点击“下载到本地”并选定目标后才新增本地明文文件。
- 回滚客户端不会删除已下载文件；iOS 的文档共享开关可以随客户端版本回滚，但已保存文件继续
  保留在应用文档目录。
