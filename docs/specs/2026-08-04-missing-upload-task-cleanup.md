# 本地源文件缺失时的上传任务处理

## 背景

文件进入待上传队列后，用户可能在上传开始前或失败后删除本地文件。此时继续重试无法恢复任务，且会让目录长期显示上传失败。

## 行为

- 上传执行器仅在系统明确返回“路径不存在”，且异常路径与任务记录的本地源文件路径一致时，将该任务移出本地上传队列。
- 手动重试、自动同步和启动续传共用同一判断；处理结果会显示本次移除的任务数量。
- 权限不足、网络失败、服务端错误、临时缓存缺失以及相册资源读取失败继续保留为失败任务，不做自动移除。
- 相册资源可能因权限变化而暂时不可见，当前不按普通文件规则自动移除，避免误判。

## 数据影响

- 只删除客户端 `SharedPreferences` 中对应的未完成上传任务记录。
- 不删除服务器已完成的文件版本，不创建远端删除事件，不修改同步目录绑定、同步历史、远端版本索引或加密密钥。
- 已产生的服务端未完成上传会话不在本次客户端清理范围内，避免客户端在未获得明确授权时删除服务端密文分片。

## 兼容与回滚

本次不修改本地任务 JSON 结构、数据库结构或同步协议。回滚到旧客户端无需迁移，但旧客户端仍会把源文件缺失任务保留为失败状态。
