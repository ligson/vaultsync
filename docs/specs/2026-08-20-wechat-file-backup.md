# 微信文件备份

## 范围

微信备份入口当前暂时下架。历史版本已经创建的微信同步根目录仍兼容显示和同步，但客户端不再允许新增微信备份或重新绑定微信目录。下架原因是微信私有图片、视频等内容受平台和版本限制，无法稳定提供“备份后即可预览/恢复”的用户体验；本次只收紧入口，不删除已有数据。

在重新开放前，必须先具备稳定、用户明确授权、跨版本可验证的桌面媒体导出方案，并能对不可预览内容给出清晰的可恢复性说明。

以下内容记录历史实现边界，供已有目录兼容和未来重新评估使用。

VaultSync 原有“微信文件备份”入口用于备份用户通过系统文件选择器可访问的微信导出目录或微信媒体目录中的图片、视频和文档。功能不读取微信聊天数据库、聊天索引、登录信息、密钥或应用私有缓存，也不绕过 Android、iOS、macOS 或 Windows 的系统权限边界。

桌面端另提供“微信完整数据归档”模式。该模式只复制用户本人电脑上已经可访问的微信账号目录，数据库以微信原始加密格式归档，不在客户端内解密、不修改、不删除源文件；它解决的是长期留存和灾备，不等同于可读聊天记录导出。

## 平台边界与自动发现

- Android：提供“授权并自动查找”，优先探测真实目录 `/storage/emulated/0/Android/data/com.tencent.mm/MicroMsg`，确认 App 进程确实可列出内容后才使用；不可读时再探测 `Pictures/WeiXin`、`DCIM/WeiXin`、旧版 `Tencent/MicroMsg/WeiXin` 等公开目录。只有 `.drive_sync` 或 `.nomedia` 的空目录不再视为有效微信目录。`MANAGE_EXTERNAL_STORAGE` 在原生 Android 上仍不能突破其他应用的 `Android/data` 隔离；Pixel 等设备通常只能自动备份微信保存到系统相册或公开目录的文件。部分厂商系统若明确授权并允许读取微信目录，VaultSync 会使用该目录，但不依赖厂商特权。
- iOS：只能备份已经进入系统照片库或 Files 的微信文件；iOS 不允许第三方应用直接读取微信沙盒。
- macOS/Windows：支持自动探测微信 3.x/4.x 常见数据目录，也可手动选择。目录绑定后由桌面文件监控触发同步，并以周期扫描兜底；不需要逐个导出微信文件。

## 扫描规则

- 支持图片、视频、文档三类，可单独勾选。
- 自动排除隐藏目录、缓存、缩略图、头像、AppBrand、地图、钱包、红包模板、小程序、聊天通知、预加载网页素材以及数据库文件；这些目录即使包含图片或视频扩展名，也不属于用户要备份的聊天文件。
- 常见图片、视频、Office/PDF/文本和压缩包按扩展名纳入。微信明确内容目录中的无扩展名文件只读取前 32 字节，识别 JPEG、PNG、GIF、WebP、HEIF/AVIF、MP4 和 PDF 的标准文件头；服务器逻辑路径补扩展名以支持预览，手机源文件不改名、不转码、不删除。无法验证格式的无扩展名文件不上传。
- 微信图片目录中的 `.dat` 原始容器按图片来源纳入，其他位置的 `.dat` 不纳入。传统桌面微信 `.dat` 常见单字节 XOR；客户端仅在解码后的 magic bytes 完整匹配 JPEG、PNG、GIF 或 WebP 时接受密钥，上传前在临时目录生成真实图片内容，服务器对象沿用原文件名但使用对应图片后缀，源 `.dat` 不改名、不删除。`WXGF/WXAM` 是另一种私有格式，不能套用 XOR；无法确认时继续原样备份为 `.dat`，避免生成打不开的假图片。
- 微信目录使用按层遍历，进入子目录前过滤缓存和数据库目录；自动发现只检查少量已知路径，不进行全盘搜索。
- 仍复用普通同步目录的写入稳定性保护、断点续传、端到端加密和上传状态记录。

## 数据兼容和安全

本地目录映射增加可选 `source_type` 和 `included_file_types` 字段，旧映射缺省为普通目录且无需迁移。服务端继续使用现有同步目录和上传协议，不新增数据库表，不删除现有目录绑定、上传任务、同步历史、密文对象或密钥。直连微信目录固定使用“保留本地文件”，VaultSync 不删除或修改微信正在使用的文件。

## 目录绑定诊断

服务器上的微信同步目录与本机的目录映射是两份独立状态。客户端升级、重装或清理本地应用数据后，服务器目录仍可能存在，但本机映射为空；此时同步主页显示“待绑定”，扫描会提示先自动查找或选择微信目录并保存，不再把未扫描的目录报告为“发现 0 个文件”。macOS/Windows 的目录操作可直接打开微信绑定对话框；若映射路径已失效或被系统隐私权限拦截，扫描会提示重新选择并授权目录。

## 后续工作

系统原生 File Provider/Cloud Files 占位、微信聊天导出包解析和跨平台后台目录授权需要分别实现，不能用普通软链接或直接读取微信数据库替代。

## 格式与权限调研结论

- Android 官方明确规定：Android 11 起普通应用不能读取其他应用的外部应用专属目录，`ACTION_OPEN_DOCUMENT_TREE` 也不能授权 `Android/data` 及其子目录。因此“所有文件访问”不等于可读取微信真实目录；华为文件管理、系统备份等系统应用可能拥有普通第三方 App 没有的平台权限。参考 [Android 11 存储空间更新](https://developer.android.com/about/versions/11/privacy/storage)。
- 当前 Android 12、微信 8.0.76 真机样本中，账户 `image` 目录 440 个文件里有 438 个是标准 JPEG/PNG，另有 2 个文件虽然命名为 `.png`，实际是标准 WebP；这些都不需要解密。优先解决 magic bytes 识别比引入解密插件更准确，也只有固定 32 字节读取开销。
- [wechat-dump](https://github.com/ppwwyyxx/wechat-dump) 的 WXGF 解码器依赖从微信 7.0.22 APK 提取的 ARMv8 私有原生库，且仓库为 GPL-3.0，不适合作为 VaultSync 的跨平台运行时依赖。传统 `.dat` 的公开实现仅是由 JPEG/PNG/GIF 文件头反推单字节 XOR，不能处理 WXGF/WXAM。
- [Shizuku API](https://github.com/RikkaApps/Shizuku-API) 可以让已安装并运行 Shizuku 的设备借用 shell/root 服务访问部分受限目录，但非 Root 设备每次重启通常需要重新启动服务，且不同系统仍可能拒绝 `Android/data`。当前不把它作为默认依赖，避免用户额外安装、调试授权和后台失效；后续可作为明确标注的高级可选数据源单独设计。
- PyWxDump 已于 2025-10-20 因合规风险移除代码和历史，不采用其数据库读取、密钥提取或聊天记录解析方案。VaultSync 的范围继续限定为用户可访问的文件备份。
