# 同步目录跨设备显示名称

## 问题

旧版同步根只保存路径哈希 `encrypted_path`。在没有该目录本地映射的其他设备上，客户端无法从哈希反推出原目录名，因此回退显示同步根 ID 的前 8 位，例如 `dc059b87`。本次样本对应原设备的 `/Users/ligson/Downloads`。

## 方案

- `sync_roots.encrypted_display_name` 保存目录最后一级名称的客户端密文。
- 客户端使用已有账号元数据密钥和同步根路径作为 AAD，通过 `XChaCha20-Poly1305` 加密；服务端只保存并转发密文。
- 新建普通同步目录、相册备份和微信备份时写入显示名称。
- 当前设备加载已有同步根时，如果服务器没有显示名称且本地存在目录映射，后台补写一次密文；不阻塞首页、不扫描远端文件。
- 其他设备加载同步根后解密显示名称；旧数据在原设备成功打开一次首页后即可被其他设备看到新名称。

## 兼容与回滚

- 数据库只新增 nullable 语义的空字符串列，已有记录保持可读，旧客户端继续使用原字段。
- 不迁移、不删除、不重写服务器对象、SQLite 既有文件、上传队列、目录绑定或密钥。
- 回滚客户端后，旧客户端仍按原逻辑显示短 ID；回滚服务端代码时保留新增列即可，不影响旧接口。
