# 文档在线预览与加载优化

## 目标

文档中心打开时先显示已建立的轻量索引，不等待历史文件全部回填；在线预览尽量由服务端按需读取明文同步目录中的文件，客户端只负责展示。加密同步目录和带密码的 PDF 不允许在线预览，只提供下载。

## 加载优化

- 文档概览和首屏列表独立请求，列表返回后立即显示，不等待设备概览；后续切换筛选和排序不重复请求设备列表。
- 明文同步目录的文件名和相对路径由服务端从明文元数据提取，客户端不再逐条解密。
- 客户端缓存同步目录名称，避免同一目录重复解密。
- 历史回填采用服务端分页；首屏已经显示后，回填完成只做保留当前内容的后台刷新。
- 时间、类型、大小继续由服务端索引分页；名称排序仍需客户端解密后排序。

## 在线预览

### 长文本阅读性能

TXT、Markdown、CSV、JSON、XML、YAML、RTF 和日志等长文本不再在首个预览请求中返回全文：

- 首个请求只返回文档元数据和章节目录。
- 正文按 UTF-8 安全窗口读取，默认每页约 16 KiB，服务端单次最多 64 KiB。
- Flutter 阅读器只保留当前页附近的少量窗口，离开阅读位置的正文字符串会释放；下一页在当前页显示时预取。
- 服务端按文件偏移读取明文同步目录，不把 10 MB 文本整体读入服务端或通过 JSON 发送到手机。
- Office/EPUB 按章节读取，章节内部仍使用同样的窗口分页；PDF 继续使用 `pdfrx` 的 HTTP Range 和渐进加载。

因此，阅读器内存占用主要与当前页附近内容和 Flutter 排版缓存有关，不与整本 TXT 文件大小线性增长。下载原文件仍是完整文件传输，和在线阅读路径分开。

服务端新增：

- `POST /api/v1/documents/plain-indexes`：只处理未加密同步目录的历史文档索引。
- `GET /api/v1/documents/{documentID}/preview`：返回阅读器章节和文本内容。
- `GET /api/v1/documents/{documentID}/content`：只允许未加密 PDF，支持 HTTP Range，供 PDF 阅读器渐进加载。

可在线阅读的格式包括 PDF、TXT、Markdown、CSV、JSON、XML、YAML、RTF、DOCX、XLSX、PPTX、ODT、ODS、ODP、EPUB 和 FB2。EPUB 优先按 `container.xml`、OPF 和 `spine` 解析真实章节顺序并提取章节标题，非标准文件回退到文件名顺序。EPUB/FB2/Office Open XML 会提取章节、正文、工作表或幻灯片文本，并在客户端提供章节选择、上一章/下一章和字号调整。

常见未加密 PalmDOC MOBI 支持在线预览。DRM、KF8/AZW3、Huff/CDIC 等复杂 MOBI 变体继续只支持下载，避免在服务端引入不安全或不完整的解码器。

TXT 和 EPUB 都由客户端使用 `TextPainter` 按屏幕实际尺寸拆视觉页，字号或横竖屏变化时只重新排版当前窗口；接近窗口末尾时再请求下一窗口。EPUB 以 OPF `spine` 顺序建立章节，章节内部和章节之间均可翻页，阅读位置保存为章节 ID 加 UTF-8 偏移。

文档中心增加“全部文档 / 书架”两个视图。首次在线打开可预览文档时加入书架，显示名称、格式、来源设备和阅读进度；用户可以继续阅读或移出书架。书架默认最多保存 100 本，只保存文档 ID、章节 ID、字节偏移和进度，不复制文档内容或封面文件。阅读进度通过服务端 API 保存，同一用户的其他设备加载书架后可以从最近位置继续阅读；文档被删除或产生墓碑后不会继续展示。当前版本使用文档类型图标作为轻量封面占位，后续可以增加服务端提取的 EPUB 封面缩略图，不改变书架数据模型。

新增 `document_bookshelf` 表和索引均为非破坏性迁移，旧客户端继续使用原有文档列表和下载接口，回滚后端代码时可保留该表。

## 安全边界

- 服务端每次预览都重新检查同步目录 `encryption_enabled=0`。
- PDF 预览还扫描 `/Encrypt` 标记，带密码的 PDF 直接拒绝。
- 服务端限制单文件在线预览大小为 64 MB，文本和多章节预览响应总量限制约为 2 MB，避免大型电子书或 Office 文件占用过多内存。
- 服务端不解密、不解析加密同步目录的文件；客户端也不会因为预览请求而拿到加密文件内容。
- 数据库只新增索引字段和接口，不删除用户数据、密文、同步历史、上传任务或密钥。
