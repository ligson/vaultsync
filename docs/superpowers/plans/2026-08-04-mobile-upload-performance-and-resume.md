# 移动端上传性能与断点恢复实现计划

1. 为上传内容增加内存和文件两种读取方式，上传执行器只按范围读取分片。
2. 为普通文件增加流式 SHA-256，为加密文件增加兼容 `VSENC001` 的流式临时密文生成与复用。
3. 上传前和 App 启动时查询服务端会话，恢复 `received_size` 并自动继续未完成任务。
4. 将上传任务 JSON 编解码移出 UI isolate，降低进度保存频率并让扫描批次主动让出事件循环。
5. 在文件状态中展示已恢复的字节数或百分比，区分准备、续传和新上传。
6. 补充流式格式兼容、范围读取、缓存复用、服务端进度校准、启动自动恢复和大队列回归测试。
7. 运行 Flutter 静态检查和全量测试，在 Android 真机验证内存、ANR、锁屏续传和覆盖升级数据保留。
