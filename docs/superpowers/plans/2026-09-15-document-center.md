# 文档中心实现计划

1. 新增非破坏性的 `document_assets`、`document_index_marks` 表和上传会话文档索引字段。
2. 新增文档列表、候选分页和幂等回填接口，覆盖设备/类型筛选及时间、类型、大小排序。
3. 上传普通文件时由客户端识别常见文档扩展名，并在文件版本完成事务中写入索引。
4. Flutter 新增文档中心模型、API 服务、分页列表、排序筛选和详情弹框，接入查看与下载。
5. 补充后端集成测试、Flutter 单元/组件测试、变更记录并运行全量验证。

数据库变更只新增表和带默认值的列。回滚保留新增结构，不清理既有文件版本、同步目录、密文对象、上传任务、同步历史或密钥。
